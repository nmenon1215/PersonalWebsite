# PersonalWebsite

Nikhil Menon's personal website and portfolio.

## Start

1. Copy `.env.example` to `.env` and set the admin credentials.
2. Install dependencies with `npm install`.
3. Run `npm run dev` to start the frontend and backend together.

## Structure

- Public landing page with social links and a resume download.
- Portfolio page with clickable project detail cards.
- Hidden login route that unlocks a protected admin shell.
